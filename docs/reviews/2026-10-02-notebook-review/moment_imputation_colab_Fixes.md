## User-visible changes

- New `HOLDOUT_START` form field in Section 5 (default −1 = middle interior patch); the default holdout moves from the series' final patch (504–511 on the sample) to an interior one (384–391), so the recorded metrics of the previous version are not comparable with the new default.
- Section 7 prints per-channel errors, a `VERDICT` line and a visible-point fidelity block; the evaluation report gains `verdict_line`, `per_channel` and `visible_point_fidelity`, and the baseline is reported as `linear_interpolation` or `last_value_hold`.
- `outputs/moment_imputation_metrics.json` gains `per_channel`, `baseline_method`, `last_value_hold_baseline`, `mae_ratio_model_over_baseline`, `verdict`, `visible_point_fidelity` and `holdout`; `linear_interpolation_baseline` is `null` when the baseline is a hold.
- The plot is now one SVG per channel (`outputs/moment_imputation_<channel>.svg`) around the held-out patch; `outputs/moment_imputation.svg` is no longer written.
- Section 3 prints the real device, dtype and weight file instead of `{'device': None, 'source': 'local-snapshot'}`.
- `evaluation_report(..., baseline_id=...)` is a new optional keyword of the package's public helper (default unchanged).
- Registry row and model card now state the recorded negative result; the status label is unchanged.
